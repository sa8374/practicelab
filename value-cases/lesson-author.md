# Value Case: Автор курса — создать курс
> Флаг: MVP

### Обстоятельства
- Автор хочет запустить новый курс и наполнить его уроками.
- Курс в черновике виден только автору.

### Возможные результаты
- Курс создан
    - Автор курса
- Курс наполнен уроками в нужном порядке
    - Автор курса

### Что понадобится
- Веб-сервис — сохраняет курс и структуру уроков, сохраняет изменения.
- Платформа PracticeLab — показывает автору черновик курса.

# Value Case: Автор курса — отправить урок на проверку

### Обстоятельства
- Автор завершил работу над уроком.
- Урок нужно проверить перед публикацией.

### Возможные результаты
- Работа над уроком завершена и передана ревьюеру
    - Автор курса
    - Ревьюер
- Автор знает, что урок на проверке
    - Автор курса

### Что понадобится
- Веб-сервис — передаёт урок ревьюеру (маршрутизация).
- Платформа PracticeLab — показывает автору, что урок отправлен на проверку.

# Value Case: Автор курса — назначить проверяющего на курс
> Флаг: MVP

### Обстоятельства
- Курс готов к проверке работ учеников.
- Нужно определить, кто будет проверять работы учеников курса.

### Возможные результаты
- Проверяющий назначен на курс
    - Автор курса
    - Проверяющий

### Что понадобится
- Веб-сервис — сохраняет назначение проверяющего и маршрутизирует работы учеников.
- Платформа PracticeLab — показывает автору назначенного проверяющего.

# Value Case: Автор курса — опубликовать готовый курс
> Флаг: MVP

### Обстоятельства
- Курс прошёл проверку и готов к публикации.
- Автор хочет сделать курс доступным для учеников.

### Возможные результаты
- Курс доступен ученикам для записи и прохождения
    - Автор курса
    - Ученик

### Что понадобится
- Веб-сервис — публикует курс и делает его доступным для записи.
- Платформа PracticeLab — показывает курс в каталоге.

# Value Case: Автор курса — обновить урок в опубликованном курсе

### Обстоятельства
- Урок уже опубликован, и его редактирование заблокировано.
- Автору нужно внести изменения, не сломав обучение текущих учеников.

### Возможные результаты
- Урок обновлён, текущие ученики продолжают учиться без сбоев
    - Автор курса
    - Ученик
- Изменения готовы к публикации
    - Автор курса

### Что понадобится
- Веб-сервис — хранит версии урока и сохраняет изменения.
- Платформа PracticeLab — показывает автору обновлённый урок.
