
# Value Case: Студент — сдать экзамен 

### Обстоятельства
- материал не отработан
- сроки поджимают

### Возможные результаты
- проработаны домашние задания
    - студент
- сданы лабораторные работы
    - преподаватель

### Что понадобится
- конспект — последовательно изложен материал курса
- учебник - материал по теме курса

# Value Case: Студент — сдать лабораторные работь

### Обстоятельства
- необходимо дополнительное оборудование
- необходимы дополнительные знания, которые нужно получить самостоятельно

### Возможные результаты
- Работа подготовлена
    - студент
- Работа сдана
    - преподаватель

### Что понадобится
- Веб-сервис — помогает получить дополнительные знания, сохраняет работу и направляет её преподавателю 
- Платформа PracticeLab — показывает статус обработки работы

# Value Case: Студент — самостоятельно проверить знания по билетам

### Обстоятельства
- имеется перечень вопросов и задач

### Возможные результаты
- Пройден коптроль по вопросам билетов
    - студент
### Что понадобится
- список вопросов 
- Веб-сервис — хранит спиок вопросов и результаты проверки
