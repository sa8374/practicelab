# Value Case: Ревьюер — проверить работу ученика
> Флаг: MVP

### Обстоятельства
- Ревьюер открыл работу ученика и хочет оценить, усвоен ли материал.

### Возможные результаты
- Работа оценена по критериям (соответствует / требует доработки / превышает ожидания)
    - оценка выбрана в селекторе и зафиксирована
- Замечания сформулированы
    - работа исчезла из очереди проверки
    - тост «Проверка завершена, результат сохранён»

### Что понадобится
- Платформа PracticeLab — показывает работу ревьюеру и результат проверки ученику.
    - Веб-сервис — отдаёт работу на проверку, сохраняет оценку и обратную связь.

# Value Case: Ревьюер — принять решение о публикации урока

### Обстоятельства
- Автор отправил урок на проверку.
- Ревьюеру нужно решить, готов ли урок к публикации для учеников.

### Возможные результаты
- Урок одобрен и опубликован
    - урок исчез из «Уроки на проверке»
    - тост «Урок опубликован»
- Урок возвращён автору на доработку с замечаниями
    - урок исчез из «Уроки на проверке»
    - тост «Урок возвращён на доработку»

### Что понадобится
- Платформа PracticeLab — показывает урок и результат решения.
    - Веб-сервис — отдаёт урок на проверку и фиксирует решение ревьюера.
