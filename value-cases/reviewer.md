# Value Case: Ревьюер — получить очередь работ на проверку

### Обстоятельства
- Ученики отправили работы на ревью, работы находятся в статусе `reviewing`.
- Ревьюеру нужно видеть, какие работы ждут его проверки, и в каком порядке их разбирать.

### Возможные результаты
- Сформирован список работ, ожидающих проверки
    - Ревьюер
- Ревьюер выбрал следующую работу для проверки
    - Ревьюер

### Что понадобится
- Веб-сервис — хранит работы и отдаёт список работ со статусом `reviewing` (маршрутизация).
- Платформа PracticeLab — показывает очередь работ и статус обработки каждой.

# Value Case: Ревьюер — проверить работу ученика и дать обратную связь

### Обстоятельства
- Ревьюер открыл работу ученика и хочет оценить, усвоен ли материал.
- Нужно дать обратную связь: что хорошо, а что доработать.

### Возможные результаты
- Работа оценена по критериям (соответствует / требует доработки / превышает ожидания)
    - Ревьюер
    - Ученик
- Сформулированы предложения по улучшению
    - Ученик

### Что понадобится
- Веб-сервис — отдаёт работу и её контент ревьюеру, сохраняет результат проверки и обратную связь.
- Платформа PracticeLab — показывает работу и позволяет оставить комментарии.

# Value Case: Ревьюер — проверить урок перед публикацией

### Обстоятельства
- Автор отправил урок на проверку (статус `review`).
- Ревьюеру нужно решить, готов ли урок к публикации для учеников.

### Возможные результаты
- Урок одобрен и опубликован
    - Ревьюер
    - Автор курса
- Урок возвращён автору на доработку с замечаниями
    - Ревьюер
    - Автор курса

### Что понадобится
- Веб-сервис — отдаёт содержимое урока на проверку и меняет статус (`review` → `published`/`draft`).
- Платформа PracticeLab — показывает урок и фиксирует решение ревьюера.

# Value Case: Ревьюер — оценить работу и зафиксировать результат проверки

### Обстоятельства
- Работа проверена, ревьюер вынес решение по оценке.
- Результат должен быть зафиксирован, чтобы ученик его увидел, а работа перешла в следующий статус.

### Возможные результаты
- Зафиксирована оценка, работа перешла в статус `graded`
    - Ревьюер
    - Ученик
- Ученик увидел результат и знает, что делать дальше
    - Ученик

### Что понадобится
- Веб-сервис — сохраняет оценку и переводит работу из `reviewing` в `graded`.
- Платформа PracticeLab — показывает результат проверки ученику.
